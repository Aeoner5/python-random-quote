# MyPlan &mdash; Founder-Ready Investment Hub

MyPlan is a prototype web experience that helps individuals showcase venture plans, pitch investors, and collaborate in real time. It blends a Kickstarter-style gallery with founder profiles and a community chat lounge, all running client-side with local storage.

## ✨ Highlights
- Curated plan cards with modal deep dives, funding progress, and traction cues
- Profile builder with live preview for entrepreneurs to craft their pitch
- Multi-room chat where planners and investors collaborate and spin up new rooms
- Responsive layout and polished styling ready for stakeholder demos

## 🚀 Getting Started
1. **Open the site**  
   Serve `index.html` or open it directly in a modern browser (Chrome, Edge, Firefox, Safari).

2. **Discover plans**  
   Use category filters and search to explore featured plans. Select “View details” for in-depth context, supporters, and milestones.

3. **Create your plan**  
   Fill out the profile builder form. The preview updates live, and submitting publishes your plan to the gallery (stored in local storage).

4. **Join the chat**  
   Set a display name, pick a room, or create your own. Messages persist locally so you can continue conversations between sessions.
